# Educa+ — Reforço Escolar
## Descrição
Site institucional responsivo desenvolvido para apresentar a Educa+, um projeto fictício
de reforço escolar.
## Objetivo
Apresentar os serviços, a proposta da instituição e facilitar o contato com estudantes e
responsáveis.
## Tecnologias
- HTML5
- CSS3
## Estrutura
- `index.html` — página inicial
- `sobre.html` — informações institucionais
- `servicos.html` — serviços
- `contato.html` — formulário e canais de contato
- `faq.html` — perguntas frequentes
- `assets/` — imagens, ícones e fontes
- `css/` — arquivos de estilos
## Acessibilidade
Foram consideradas semântica HTML, textos alternativos, contraste, labels em
formulários e navegação clara.
## Execução
Por ser um projeto Front-End estático, basta abrir o arquivo `index.html` em um
navegador ou utilizar uma extensão/servidor local para desenvolvimento.
